🍫 Chocolate Sales Data - Exploratory Data Analysis
![image](https://github.com/user-attachments/assets/eb316409-3578-442f-b8a0-dda9c02c1ac3)

This repository contains an exploratory data analysis (EDA) of chocolate sales data. The analysis focuses on cleaning, transforming, and visualizing the data to uncover insights such as total sales by country, top-performing salespeople, and product-level performance.
